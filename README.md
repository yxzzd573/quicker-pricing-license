## 下单前要自己核对的几件事

这些条款页面一般都会写，但位置比较分散，付款前花两分钟过一遍不吃亏。

- **授权时长**：买的是一年还是更久，到期之后是直接停用，还是退回免费版。
- **授权设备数**：能装几台电脑，换电脑之后旧授权怎么处理。
- **续费价格**：第二年按什么价续，会不会比首单贵。
- **版本更新**：授权期内的大版本更新是否包含在内。
- **退款与激活期限**：虚拟授权通常对激活时间有要求，退款条件各平台不同，下单前在商品页或帮助页确认。
- **发票**：需要报销的话，先看平台是否支持开票。
